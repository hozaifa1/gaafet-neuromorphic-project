# Device-optimization sweep data (publication tables)

Tidy/long CSVs distilled from the coordinate-descent optimization of the
GAA-FeFET LIF neuron (`OPT_LOG.md`, raw rows in `docs/turn*.tsv`). One parameter
optimized per turn; the winning value is carried into the next turn's base mesh.

Generated by `build_sweeps.py` (this folder). Source files are not modified.

## Units / column conventions
- Currents (`id_off_uA_um`, `id_on_uA_um`) are µA/µm. `id_off` = ID_rest; `id_on` = retained on-state (IDon; for `tox_sweep` it is IDp9).
- `window` = ID_on / ID_off (FeFET memory-window-as-current-ratio).
- `v_op_V` = program operating voltage; `qg_C` = gate charge (C); `igain` = graded-integration gain (per-pulse fidelity).
- All sorted ascending by the swept parameter (first numeric column).

## CSV -> intended paper figure/table

| CSV | Swept param | Intended paper element |
|---|---|---|
| `tox_sweep.csv` | T_ox (nm) | FIGURE — window/off-state vs interfacial-layer thickness (the central FeFET coupling lever) |
| `tfe_sweep.csv` | T_fe (nm) | FIGURE — window & operating voltage/energy vs ferroelectric thickness |
| `tsi_sweep.csv` | T_si (nm) | FIGURE — window vs nanosheet body thickness (electrostatic control) |
| `vread_sweep.csv` | VREAD (V) | FIGURE — read-disturb / integration trade-off vs read bias (motivates VREAD=-0.5) |
| `nsub_sweep.csv` | N_sub (cm^-3) | TABLE — body-doping null result (off-state floor-limited) |
| `lscaling.csv` | L_gate / L_ov (nm) | TABLE — confirmatory geometry lock (channel + overlap scaling) |
| `optimization_trajectory.csv` | turn | summary TABLE/FIGURE — coordinate-descent path to the optimized device |

## Lead-researcher presentation recommendation
- **Figures (monotone, informative trends):** `tox_sweep`, `tfe_sweep`, `tsi_sweep`, `vread_sweep`.
- **Tables (null / confirmatory):** `nsub_sweep` (doping barely moves a fully-depleted 5 nm body; off-state at the numerical floor) and `lscaling` (geometry scaling only trades SCE/GIDL; confirms L_gate=100 nm, L_ov=15 nm).

## Notes on specific files
- `tox_sweep.csv`: two eval contexts per device, `eval` column = `fixed4V` (over-driven V_pgm=4.0) vs `subcoercive` (each device's sub-coercive operating point). `window` is blank for these rows (turn-2 TSV predates the WIN column); the T_ox=2.0 nm baseline row carries window=2.6 from OPT_LOG.
- `tsi_sweep.csv`, `nsub_sweep.csv`: include the carried-forward baseline row (T_si=15 nm; N_sub=1e16) reconstructed from OPT_LOG.
- `tfe_sweep.csv`: T_fe=10 nm row is the si05 base (mesh `si05`). Optimized device = T_fe=7 nm (window 96240, V_op=2.5 V).
- `lscaling.csv`: `fe07_reference` (L_gate=100, L_ov=15) is the locked geometry; the two scaled points are 6x worse.
- `optimization_trajectory.csv`: window/off/V_op per turn are the KEEP / CURRENT-BEST values from OPT_LOG. Turns 3-4 windows were measured at the fixed V_pgm=4.0 eval; turns 2/5/6 at the sub-coercive V_op. End point = optimized device (T_OX=1, T_SI=5, T_FE=7 nm, N_SUB=1e16, L_GATE=100, L_OV=15 nm, WF=4.35; window ~9.6e4 at V_op=2.5 V).
